安装完成 · 接下来 5 步

  1. 打开 App：应用程序 → Google Remote Voice（首次右键 → 打开）。在窗口里授予蓝牙 / 辅助功能 / 输入监控。
  2. 配对遥控器：系统设置 → 蓝牙，连接 Chromecast Remote。
  3. 装 PacketLogger（14 键需要）：从 Apple 官方下载页 下载 Additional Tools for Xcode（正式版，需 Apple 账号），打开 DMG 把 Hardware/PacketLogger.app 拖进应用程序；或在 App 里点「选择工具…」指向它。
  4. 设输入法：豆包输入法 → 语音输入 → 麦克风选 Remote Buddy Mic；长按模式快捷键（如左⌘+左⇧）。回到 App 把「语音键」录成同一个组合键。
  5. 开按键接收：App 里点「开启按键接收」→ 输管理员密码。先勾「按键检测模式」把 14 键各按一遍核对计数，再取消勾选启用映射。

语音：按住语音键 >1.5 秒再说话，松开即停（遥控器松开就停止推流，免提/免按模式不适用）。

详细文档与排障见项目 README 与 docs/。反馈建议欢迎到 GitHub Issues。
