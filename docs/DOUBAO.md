# 豆包输入法配置（Enhanced）

让遥控器语音经 **Remote Buddy Mic** 进入豆包输入法，按住说话、松开出字。

## 1. 麦克风

豆包输入法 → 设置 → **语音输入** → **麦克风选择** → 选 **`Remote Buddy Mic`**。

- 默认是「MacBook Pro 麦克风」，**必须手动改**，否则豆包听的是笔记本麦克风，遥控器声音进不去。
- 豆包 Mac 版**不显示 transport=Virtual 的普通虚拟声卡**（如原版 BlackHole）。一体包自带的 Remote Buddy Mic 是 USB-transport 派生驱动，豆包能识别。

## 2. 语音快捷键（两边必须一致）

豆包「语音输入模式」有两种：

| 模式 | 豆包默认键 | 行为 | 与遥控器 |
| --- | --- | --- | --- |
| **长按模式** | 左⌘ + 左⇧ | 按住说话，松开结束 | ✅ 推荐，与遥控器「按住推流、松开停流」天然匹配 |
| 免按模式 | 左⌥ | 按一次开始，再按任意键结束 | ⚠️ 遥控器松开即停流，免提原理上不兼容 |

**推荐用长按模式**：

1. 豆包侧保持「长按模式 = 左⌘ + 左⇧」（或你自定义的组合键）。
2. 回到 Google Remote Voice → 「语音键」→ **录制** → 在 **Mac 键盘**上按下同一个组合键（如左⌘+左⇧）。
3. 勾选「同时开启麦克风（灌入虚拟声卡）」。

> 关键：豆包只认**真实的修饰键 keyDown/keyUp 事件序列**。本增强版的 `postKey` 会真实按下左⌘、左⇧（纯修饰键组合也支持）再反序释放；旧版仅给主键挂 flags 的做法豆包不触发。

## 3. 测试

光标放进任意输入框 → **按住遥控器语音键 >1.5 秒** → 说话 → 松开 → 豆包出字。

- 按太短（<1.3 秒）遥控器还没开始推流，会得到空流。
- 日志里 `语音接收统计：N 包 / X 秒` 接近 62 包/秒为正常。

## 其它输入工具

- **Handy**（本地离线转写）：输入设备选 `Remote Buddy Mic`，录音方式 Push to Talk，快捷键与 App 语音键一致。见上游 [HANDY.md](HANDY.md)。
- **Typeless**：Settings → Audio → Microphone 可直选 `Remote Buddy Mic`；但其触发是「点按开始/再点按结束」，与遥控器按住说话不匹配，需另行适配。
